1. Introdução — O que é o Furpal?

O Furpal Imobiliária é um sistema de site completo para imobiliárias. Pense nele como o "painel de controle" do seu site: você faz as alterações aqui e elas aparecem automaticamente no site.

Com ele você pode gerenciar tudo do seu site imobiliário sem precisar saber programação:

O que você quer fazer?Onde fazer?
Alterar o logo ou telefoneAba "Geral"
Adicionar uma casa para vendaAba "Imóveis"
Publicar um artigo no blogAba "Blog"
Colocar o depoimento de um clienteAba "Depoimentos"
Mudar as informações de uma cidadeAba "Região"
Adicionar um novo corretorAba "Equipe"
Salvar tudo no banco de dadosBotão "💾 Salvar (BD)"
💡 Boa notícia: Você não precisa saber HTML, PHP ou programação. O painel foi feito para ser usado por qualquer pessoa da imobiliária.

O sistema pode funcionar de duas formas:

  • Modo Frontend (padrão): As alterações são salvas em um arquivo e publicadas no GitHub Pages. Ideal para começar.
  • Modo Banco de Dados: As alterações vão para um banco MySQL via internet. Mais seguro e recomendado para uso profissional.

2. Acessando o Painel Administrativo

O painel fica dentro do próprio site. Você não precisa instalar nada.

Passo a passo:

1. Abra o site no navegador
2. Na barra de endereço, adicione ?edit=1 no final da URL

Exemplo:
https://www.furpal.com.br/?edit=1

3. Pressione Enter
4. Aparecerá uma tela de login. Digite:   Usuário: admin   Senha: admin123 5. Pronto! O painel aparece na parte de cima da página.
⚡ Dica: Marque "Lembrar login" para não precisar digitar a senha toda vez.
⚠️ Importante: Em produção (site no ar), troque a senha padrão! Isso é feito no arquivo de configuração do servidor.

Como editar:

1. Clique na aba "📊 Geral"
2. Os campos aparecem na área de conteúdo
3. Preencha ou altere os valores desejados
4. A mudança já aparece no site (role a página)
5. Para salvar permanentemente, clique [💾 Salvar (BD)] no final
⚡ Teste agora: Altere o subtítulo e veja a mágica acontecer em tempo real!

Passo a passo para adicionar um imóvel:

1. Clique em [+ Novo Imóvel]
2. Preencha os campos no formulário que abrir
3. Clique em "Salvar" no formulário
4. O imóvel aparece na tabela e no site
5. Clique [💾 Salvar (BD)] para salvar no banco
💡 Dica de fotos: As imagens precisam estar hospedadas em algum lugar (pode ser no próprio servidor ou em serviços como Imgur, Google Fotos, etc.). Copie a URL da imagem e cole no campo.

6. Aba "🏗️ Empreendimentos"

Funciona de forma similar aos imóveis, mas é voltada para empreendimentos (prédios inteiros, condomínios, loteamentos).

Diferenças principais dos imóveis comuns:

  • Tem planta (imagem da planta baixa)
  • Tem diferenciais (itens de destaque do empreendimento)
  • Pode ter status como "Lançamento", "Em obras" ou "Pronto"
  • Cada empreendimento tem sua página de detalle com todas as informações
⚡ Exemplo: Se você está vendendo um prédio novo com 20 apartamentos, cadastre ele aqui como "Empreendimento", não como 20 imóveis separados.

7. Aba "📝 Blog"

Gerencia as postagens do blog do seu site. Cada postagem pode conter:

  • Título — O nome do artigo
  • Resumo — Um texto curto que aparece na lista de posts
  • Conteúdo — O texto completo (pode usar HTML básico para formatar)
  • Imagem de destaque — A foto principal do post
  • Categoria — Para organizar os posts (ex: "Dicas", "Mercado", "Novidades")
  • Data — Data de publicação

Como escrever o conteúdo:

Você pode usar tags HTML simples para formatar o texto:

<h2>Título da seção</h2>
<p>Parágrafo normal...</p>
<strong>texto em negrito</strong>
<img src="URL-da-imagem">

Se não souber HTML, apenas escreva o texto normal usando parágrafos simples.

14. Aba "⚙️ Config" — Modo Banco de Dados

Esta aba permite ativar o Modo Banco de Dados, que salva as informações em um banco MySQL ao invés de apenas no arquivo do site.

💡 Quando usar: Se você tem um plano de hospedagem (Hostinger, InfinityFree, etc.) com suporte a PHP e MySQL, ative o modo BD para maior segurança e confiabilidade.

Como ativar:

1. Vá na aba "⚙️ Config"
2. Marque a opção "Ativar modo BD"
3. No campo "URL Base da API", digite: /api.php
4. Clique em "Salvar Config"
5. A página vai recarregar automaticamente
⚠️ Antes de ativar: Certifique-se de que o arquivo api.php foi enviado para o servidor e que o banco de dados está configurado corretamente (veja o Guia de Configuração Técnica para mais detalhes).

Salvando os dados no banco:

Com o modo BD ativo, um novo botão aparece no painel:

┌──────────────────────────────────────────────────────┐ │ [💾 Salvar (BD)] — Salva todos os dados no MySQL │ │ [🚀 Publicar] — Publica no GitHub Pages │ └──────────────────────────────────────────────────────┘

Use o "💾 Salvar (BD)" sempre que fizer alterações e quiser salvá-las permanentemente no banco de dados.

15. Publicando as Alterações

Existem duas formas de publicar as alterações, dependendo do modo que você está usando:

ModoBotãoO que faz
Frontend🚀 PublicarEnvia os dados para o GitHub Pages (requer token)
BD💾 Salvar (BD)Salva os dados no banco MySQL

Fluxo de trabalho recomendado:

1. Faça as edições no painel administrativo
2. Confira as alterações rolando a página para baixo
3. Se estiver satisfeito, clique em [💾 Salvar (BD)]
4. Uma mensagem "✅ Dados salvos no BD!" confirma o sucesso
5. Recarregue a página para ver o resultado final

16. Dicas e Solução de Problemas

🎯 Dicas para usar o painel:

  • Sempre confira as alterações rolando a página para baixo antes de salvar
  • Use imagens no formato JPG ou WebP para fotos, PNG para logos
  • Não use imagens muito pesadas — fotos com mais de 500KB podem deixar o site lento
  • O botão "Salvar (BD)" salva TUDO de uma vez (todas as abas)
  • Para testar sem medo, abra o site em outra aba do navegador enquanto edita

❓ Problemas comuns:

ProblemaCausa provávelSolução
"Erro 500" ao salvar no BD Conexão com banco de dados incorreta Verifique as credenciais no arquivo api-config.php
Imagens não aparecem (403) Proteção de hotlinking no servidor Entre em contato com o suporte técnico
Alterações não aparecem no site Não salvou no BD ou cache do navegador Clique em "Salvar (BD)" e recarregue (Ctrl+F5)
Não consigo acessar o painel URL sem ?edit=1 ou senha errada Adicione ?edit=1 na URL e tente admin/admin123
A URL do site está acumulando (ex: /sobre/comprar/...) Configuração de BASE_PATH incorreta Informe ao suporte técnico
