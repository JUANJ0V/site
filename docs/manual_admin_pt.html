1. Introdução — O que é o Painel Admin?

O Painel Admin é a área privada do site Furpal. É aqui que você edita todo o conteúdo do site sem precisar saber programação: imóveis, lançamentos, blog, FAQ, depoimentos, parceiros, equipe, cidades da região e todas as configurações gerais (logo, WhatsApp, textos das seções, redes sociais etc.).

Tabela rápida de "o que eu quero fazer / onde fica":

O que você quer fazerOnde fica no painel

Definir preço, entrada, taxa e prazo padrão da simulação de financiamentoAba Financiamento

💡 Boa notícia: Você não precisa saber HTML, PHP ou programação. O painel foi feito para uso de qualquer pessoa da imobiliária.
🖥️ Como o painel funciona: Quando você clica em "💾 Salvar", o painel gera o arquivo js/data.js e o grava no próprio servidor (via save.php). Não usa banco de dados externo: tudo fica no seu site. As imagens ficam em pastas do site (images/ e videos/).

2. Acessando o Painel (login)

O painel fica dentro do próprio site. Você não precisa instalar nada.

Passo a passo:

  1. Abra o site no navegador (ex.: https://www.furpal.com.br).
  2. No final da URL, adicione ?edit=1 e pressione Enter.

5. Aba "Financiamento" — Parâmetros da Simulação

Esta aba controla a calculadora de financiamento do site (a seção que mostra "entrada, parcelas, taxa de juros").

  • Eyebrow e Título: textos da seção de financiamento.
  • Preço padrão (R$): valor inicial do imóvel na simulação (ex. 500000).
  • Entrada padrão (R$): valor inicial da entrada (ex. 100000).
  • Taxa de juros padrão (% a.a.): taxa usada por padrão (ex. 8.5).
  • Prazo padrão (meses): número de parcelas (ex. 240 = 20 anos).
💡 Importante: os valores "padrão" são apenas o ponto de partida do simulador — o visitante pode ajustá-los na página.

Desabilitar o painel (site final)

Quando o site for entregue, você pode desligar o painel para ninguém acessar ?edit=1. Isso é feito mudando a primeira linha do arquivo js/admin.js:

const ADMIN_ENABLED = true;   →   const ADMIN_ENABLED = false;

Depois é preciso atualizar o arquivo no servidor (via FTP/Hospedagem ou pedindo ao desenvolvedor). Enquanto ADMIN_ENABLED = true, o painel continua ativo.

15. Senha do Servidor e Email (api-config.php)

A senha de acesso ao painel e o email que recebe o formulário de contato não ficam no código do site: ficam em um arquivo fora do GitHub, chamado api-config.php, dentro da pasta do site no servidor.

Servidor → raiz do site → api-config.php
<?php
  // ===== CONFIGURAÇÕES DA API / SERVIDOR =====
  define("API_PASSWORD", "RankfdIFPosRKqlrJMTU9g");
  define("CONTACT_EMAIL", "contato@furpal.com.br");
  ?>

O que cada linha significa:

ConstanteFunção
API_PASSWORDA senha do servidor. É ela que você digita no login do painel (tela ?edit=1). Protege o login (auth.php), o salvamento (save.php) e o upload de imagens (upload.php).
CONTACT_EMAILO email que recebe as mensagens do formulário de contato do site (via send-contact.php).

Como trocar a senha do painel:

  1. Acesse o servidor (painel da hospedagem ou FTP).
  2. Abra o arquivo api-config.php na raiz do site.
  3. Troque o valor de API_PASSWORD por uma senha nova e longa.
  4. Salve o arquivo. Pronto: o painel passa a exigir a senha nova.
⚠️ Muito importante: NÃO envie o arquivo api-config.php para o GitHub nem o compartilhe. Quem tiver essa senha consegue entrar no painel. Mantenha-o apenas no servidor.
⚠️ Não use caracteres com acento nem aspas simples dentro do valor da senha. Se a senha tiver aspas simples ('), o arquivo quebra e o site para de funcionar.

17. Subindo Imagens e Vídeos

Em vários formulários existe o botão 📷 Upload ao lado do campo de imagem. Ele envia o arquivo direto para o servidor (pastas images/ para fotos e videos/ para vídeos) e preenche a URL sozinho.

Como usar:

  1. Clique no botão 📷 Upload ao lado do campo (ex. "Imagem principal").

  3. Aguarde a mensagem "✅ URL adicionada!" — o campo de URL é preenchido automaticamente.
  4. Clique em 💾 Salvar no servidor para publicar.

18. Backup e Restauração (Export / Import)

O site Furpal guarda todo o conteúdo (imóveis, lançamentos, blog, etc.) no arquivo js/data.js do servidor. Para garantir segurança, use o recurso Export / Import da aba Config.

📤 Fazer backup (exportar):

  1. Vá em Config → 📤 Exportar dados (JSON).
  2. O navegador baixa um arquivo chamado furpal-backup-2026-08-10.json (com a data do dia).
  3. Guarde esse arquivo em um local seguro (nuvem, pendrive, email). Ele contém todos os dados do site.
💡 O que o backup inclui: todas as configurações gerais, estatísticas, imóveis, lançamentos, FAQ, depoimentos, parceiros, equipe, informações das cidades e artigos do blog. As imagens/vídeos não entram no JSON — elas já estão nas pastas images/ e videos/ do servidor.

📥 Restaurar (importar):

  1. Vá em Config → 📥 Importar dados (JSON).
  2. Selecione o arquivo de backup que você baixou.
  3. O painel recarrega os dados no formulário.
  4. Atenção: a importação só fica no navegador. Clique em 💾 Salvar no servidor para gravar de volta no site.
⚠️ A importação SUBSTITUI os dados atuais pelas informações do arquivo. Faça um Export antes de importar, para não perder nada por engano.

19. Dicas, Segurança e Solução de Problemas

🔐 Segurança (não pule!)

  • Use uma senha longa e única no api-config.php (mínimo 12 caracteres, com letras e números).
  • Nunca compartilhe o arquivo api-config.php nem a senha por mensagem com estranhos.
  • Para não deixar o painel acessível a visitantes, desligue com ADMIN_ENABLED = false (seção 14) quando o site for entregue.
  • Mantenha um backup JSON atualizado (seção 18).

Não consigo entrar no painel ("Senha incorreta")A senha digitada não é a do API_PASSWORD no api-config.php do servidor. Confira o arquivo e o valor exato (atenção a maiúsculas/minúsculas).
"Defina a senha do save.php na aba Config" ao salvarVá na aba Config, digite a senha do servidor e clique em 💾 Salvar senha.
Editei mas o site continua igualVocê esqueceu de clicar em 💾 Salvar no servidor. Depois de salvar, atualize a página do site (F5).
Imagem do parceiro/imóvel em brancoO campo de imagem está vazio. Envie a foto pelo 📷 Upload e salve.
Foto não sobe (upload falha)A imagem é muito grande. Reduza para menos de ~500 KB (ou máximo 2 MB) e tente de novo.
Mapa não mostra um imóvelO imóvel está sem Latitude/Longitude. Preencha esses dois campos no formulário do imóvel.
Site aparece sem uma seçãoO título (ou eyebrow) da seção está vazio na aba Geral — preencha os dois e salve.
Não recebo emails do formulário de contatoConfira o CONTACT_EMAIL no api-config.php e a pasta spam/lixo do email. Se o host bloquear, o site mostra um botão de WhatsApp como alternativa.
Quero recuperar tudo de um backupAba Config → 📥 Importar dados (JSON), escolha o arquivo e depois 💾 Salvar no servidor.
