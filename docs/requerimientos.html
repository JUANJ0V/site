2. Funcionalidades del Sistema

2.1 Gestión de Inmuebles

Completo CRUD

  • Registro de inmuebles para venta y alquiler
  • Campos: tipo, categoría, título, precio (texto y número), ubicación, mapa, coordenadas, estado, descripción corta y larga
  • Características: habitaciones, baños, garaje, área
  • Campos para terrenos: frente, fondos, zona, topografía
  • Imagen principal + galería múltiple de imágenes
  • Video embebido (YouTube/Vimeo)
  • Lista de características personalizadas
  • Ordenación por precio, tipo, ubicación
  • Visualización en tarjetas (compra y alquiler separados)
  • Página de detalle con galería en pantalla completa
  • Mapa interactivo con Leaflet + OpenStreetMap

2.2 Gestión de Emprendimientos

Completo CRUD

  • Registro de emprendimientos inmobiliarios
  • Campos: nombre, descripción, ubicación, coordenadas, galería, video
  • Estado: Lanzamiento, En obras, Listo
  • Planta y diferenciales del proyecto
  • Página de detalle individual con mapa y galería

2.3 Blog

Completo CRUD

  • Publicaciones con título, resumen, contenido HTML
  • Imagen destacada, categoría y fecha
  • Lista de artículos en sección blog
  • Página de detalle individual

2.4 Testimonios

Completo CRUD

  • Nombre, descripción y texto del testimonio
  • Visualización con estrellas y formato destacado

2.5 FAQ

Completo CRUD

  • Preguntas y respuestas en formato acordeón
  • Apertura/cierre con animación

2.6 Socios

Completo CRUD

  • Nombre, logo, URL del sitio web
  • Logos en grid en la página principal

2.7 Región (LOCATIONS_INFO)

Completo Nuevo

  • Gestión por ciudad/región con múltiples campos
  • Tagline, imágenes, introducción, historia, seguridad
  • Playas con nombre y descripción
  • Destacados y puntos de interés

2.8 Equipo

Completo CRUD

  • Corredores con nombre, cargo, foto, CRECI, teléfono, email
  • Visualización en tarjetas

2.9 Estadísticas

Completo CRUD

  • Indicadores numéricos con etiqueta, valor e icono
  • Animación de conteo al hacer scroll

2.10 Panel Administrativo

Completo

  • Acceso vía parámetro ?edit=1 en URL
  • Login con usuario y contraseña (verificación cliente/servidor)
  • 11 pestañas de gestión: General, Inmuebles, Emprendimientos, Blog, Testimonios, FAQ, Socios, Región, Equipo, Estadísticas, Config
  • Editor visual tipo formulario para cada tipo de contenido
  • Previsualización en tiempo real (syncToLive)
  • Modo Frontend: publicación directa a GitHub Pages
  • Modo BD: persistencia en MySQL vía API PHP
  • Minimización automática de JS/CSS para producción

2.11 Calculadora de Financiamiento

Completo

  • Cálculo de cuotas mensuales con tasa configurable
  • Campos: valor del inmueble, entrada, plazo, tasa de interés
  • Resultado en tiempo real al modificar valores

2.12 Mapa Interactivo

Completo

  • Integración con Leaflet + OpenStreetMap (gratuito, sin API key)
  • Marcadores para propiedades y emprendimientos
  • Popups con información y foto
  • Vista satelital y de calles

2.13 Modo Oscuro

Completo

  • Alternancia claro/oscuro con botón en navbar
  • Persistencia de preferencia en localStorage
  • Todas las secciones adaptadas al tema

2.14 Modo Base de Datos

Completo Nuevo

  • API REST en PHP puro (sin frameworks)
  • Endpoints: ping, all, collections, login, save, setup, users
  • PDO con prepared statements para seguridad SQL
  • Autenticación opcional vía Bearer token
  • Soporte para múltiples colecciones con tablas separadas
  • Esquema SQL exportable (schema.sql)
  • Setup automático vía endpoint

2.15 Traducción / i18n

Parcial

  • Interfaz del sitio preparada para traducción vía Google Translate
  • Widget de Google Translate embebido
  • Texto en tarjetas y secciones traducible

3.2 Flujo de Datos — Modo Frontend

  1. Las constantes se definen en data.js (archivo estático)
  2. app.js renderiza el contenido usando estas constantes
  3. El panel admin (admin.js) modifica una copia en memoria (_data)
  4. syncToLive() actualiza el DOM en tiempo real
  5. Para publicar: se envía a GitHub Pages (sobrescribe data.js)

3.3 Flujo de Datos — Modo BD

  1. Admin edita → _data se actualiza → syncToLive() actualiza DOM
  2. Admin hace clic en "💾 Guardar (BD)" → saveToApi()
  3. POST a api.php con todo el JSON → se guarda en MySQL
  4. Al recargar la página: app.js llama a DataProvider.getAll()
  5. GET /api.php?action=all → reemplaza las constantes globales con datos de BD
  6. Re-renderizado completo del sitio con datos frescos

5. Configuración y Despliegue

5.1 GitHub Pages

  1. Crear repositorio en GitHub
  2. Subir todos los archivos (index.html, js/, css/, images/, etc.)
  3. Ir a Settings > Pages > Source: main branch / (root)
  4. El archivo 404.html maneja la redirección SPA automáticamente
  5. Opcional: configurar dominio personalizado

5.2 Hosting PHP/MySQL (Hostinger, InfinityFree, etc.)

  1. Subir todos los archivos vía FTP al servidor
  2. Crear una base de datos MySQL desde el panel de control
  3. Copiar api-config.example.php a api-config.php y completar credenciales
  4. Importar schema.sql en la base de datos (phpMyAdmin)
  5. O alternativamente, acceder a /api.php?action=setup para setup automático
  6. Verificar que PHP tenga extensión PDO MySQL habilitada
  7. Configurar SSL/HTTPS si está disponible

6. Seguridad

  • Panel admin: Protegido por login (verificación cliente y servidor)
  • API: Autenticación opcional vía Bearer token (API_PASSWORD)
  • SQL: Prepared statements PDO contra inyección SQL
  • Datos: Validación en frontend antes de enviar
  • Hotlinking: Protección configurable en .htaccess
  • HTTPS: Recomendado para producción

7. Mantenimiento

  • Las tablas se limpian (TRUNCATE) antes de cada guardado completo
  • Las colecciones de BD mode aceptan arrays vacíos (limpia la tabla)
  • Minificar JS/CSS después de cada modificación
  • Actualizar números de versión (?v=N) para romper caché del navegador
